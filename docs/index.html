EMOJI CLASH

🙂 🥷 💂 🐒 🧙 🧛 — a two-player real-time strategy game that lives in one HTML file, renders itself entirely in system emoji, and plays peer-to-peer over WebRTC.
▶ Play in your browser Source on GitHub

What it is

One static page, about 190 KB, with no external references of any kind. No game server, no lobby, no backend, no build step at run time. Two browsers exchange a five-character room code and then talk directly to each other for the rest of the match.

Three resources, and a supply line

💾 bits → 🗄️ DriveEverywhere, quick to mine. The bread and butter.
🎨 pixels → 🖼️ GalleryFive times scarcer and nearly twice as slow to dig.
☁️ Cloud → 🤖 slopFuses 2 bits + 1 pixel. Nothing moves by itself — Engineers carry every load, including the finished slop.

An army you type out

A ⌨️ Keyboard types fighters into existence. A 📱 Social Feed sours a Smiley one step at a time, and each step costs one 🤖 that somebody physically carried to the building:

🙂→😐→🙁→😠😡 detonates on death 🥷Ninja💂Guard 🐒Monkey — fouls ground with 💩 🧙Wizard🧛Vampire 👨🏻‍🔧Janitor — the only 💩 counter

Under the hood

  • Deterministic lockstep. No world state crosses the wire, only commands. Both peers run an identical integer-only simulation and compare checksums to catch any divergence.
  • Flow-field pathing. Obstacles rasterise onto a tile grid; each goal gets a Dijkstra field, shared by everyone heading there.
  • Stigmergy. Carriers lay pheromone trails, collisions mark jams that later routes bend around, and crews spread across deposits instead of stacking. Press T in game to see it.
  • Emoji as the entire art pipeline. No sprites, no images. Glyphs are rasterised once and blitted; team colour comes from the ring behind, drawn at exactly the collision radius.
Built with TypeScript, Vite and a canvas. Source and full write-up on GitHub.
